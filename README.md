# Student Record Management System

## About the Project
A Python-based application to manage student records using functions, file handling, and exception handling.

## Features
- Add student records
- View student records
- Search students by ID
- Update student information
- Delete student records
- Store data in JSON and CSV formats
- Handle invalid inputs and file errors

## Technologies Used
- Python
- JSON
- CSV
- Visual Studio Code

## How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
python main.py
```

## Project Files
- `main.py` – Main application
- `student_manager.py` – Student management functions
- `file_handler.py` – File handling functions
